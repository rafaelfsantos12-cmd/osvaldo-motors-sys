O objetivo é criar um sistema para o senhor Osvaldo organizar os clientes, os carros e os consertos da oficina. O sistema permitirá cadastrar o nome do cliente, o veículo e a placa, além de registrar os serviços realizados.

A ideia é substituir a papelada usada no dia a dia, deixando as informações dos clientes, veículos e serviços mais organizadas e fáceis de consultar.
